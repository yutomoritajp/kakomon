# 概要

バージョン0で達成したい要求とスコープの分割について記載する。

## 要求

### v0の位置付け

v0(バージョン0)ではアプリケーションとして動作する最低限の機能を実装する。
フロントエンド・サーバーサイド・DBが疎通している状態にするがAIとチャットする機能は対応しない。

### 対応すること

データベーススペシャリスト試験(DB)の令和7年度(秋)の午前Ⅰの過去問演習ができるようにする。具体的には以下の機能を持つ。

- 試験回・試験区分の選択（ただし、令和7年(秋)の午前Ⅰしか選択できない。）
- 問題の表示
- ユーザー解答・および採点
- 結果表示・「試験回・試験区分の選択」へ戻る遷移

#### スコープ

1. s1_basic_design: 画面遷移ができる状態にする。
2. s2_basic_design: データ保持の方針を決定し、DBと初期マイグレーションファイルを作成する。
3. s3_basic_design: スコープ2で作成したDBやストレージに必要なデータを作成する。
4. s4_basic_design: 画面とDBにデータを渡すAPIを作成する。（フロント側とサーバーサイド側でデータのやり取りをする）
5. s5_basic_design: 細かい挙動調整など。

### 対応しないこと

- AIチャット機能。（別バージョンで対応）
- 該当年度以外の試験データ作成など
